# Go Getter 3

Interactive vocabulary trainers for *Go Getter 3* (grade 5): picture flashcards with Russian translations and audio, then many drills with instant checking — listening, translation, sentences, spelling.

Site: https://elvisk2079-ux.github.io/Go-getter-3/

- Shops — shops, things you can buy, describing shops (too / not … enough / as … as)
- Places in a school
- `src/` — sources and build scripts (`sh src/build_all.sh`)

Pictures: [Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google, Apache License 2.0.
